Dusk 1.2.1

**Verbeterd**
- Tekst wordt nu door Windows zelf gezet, dezelfde techniek als Verkenner en Instellingen van Windows. Daardoor is alles scherp, ook in het venster Instellingen.
- Mica (de vervaagde achtergrond) toont alleen nog de kleur van je bureaublad, geen vormen of vlekken meer.
- Heb je een effen kleur of Windows Spotlight als bureaublad, dan laat Dusk geen oude achtergrondfoto meer zien.
- Halfvette koppen, zoals in Windows 11.
- Kortere uitleg bij "Waar opent Dusk", zodat die niet meer wordt afgekapt.

**Bijwerken:** heb je Dusk 1.1.0 of nieuwer, ga dan naar Instellingen > Bijwerken en klik op Nu bijwerken. Anders: download `Dusk-Setup.exe` hieronder.
